# Installation (Chrome, Brave, Edge, etc.)

Only use the first option if you know your browser is ok with installing unsigned CRX packages. Otherwise, use the second option.

**Option 1: unsigned package installation**

1. [Download for Chrome, Brave, Edge, etc.](https://github.com/merissler/Better-Jira/releases/latest/download/better-jira.crx)
   - If you get `CRX_REQUIRED_PROOF_MISSING` after downloading the file, switch to option 2
3. Enable developer mode in `chrome://extensions/`
4. Drag n' drop

**Option 2: load unpacked source**

1. [Download source](https://github.com/merissler/Better-Jira/archive/refs/heads/main.zip)
2. Unzip and move folder to a permanent directory (or just leave it in Downloads if that's how you live your life)
3. Enable developer mode in `chrome://extensions/`
4. Select 'Load unpacked' and choose the `src` directory ([screenshot](https://github.com/user-attachments/assets/02b52629-f400-4c5b-9a86-1c01e16ab3c0))

# Installation (Firefox)

Standard releases of Firefox no longer allow the installation of unsigned add-ons, so [Firefox Developer Edition](https://www.firefox.com/en-US/channel/desktop/developer/) is required for this.

1. [Download for Firefox](https://github.com/merissler/Better-Jira/releases/latest/download/better-jira.xpi)
2. Disable `xpinstall.signatures.required` in `about:config`
3. Drag n' drop into `about:addons`
